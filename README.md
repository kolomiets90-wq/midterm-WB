# Прогнозирование цен товаров Wildberries

## Задача

По характеристикам карточки товара прогнозировать
итоговую цену (`final_price`).

Тип задачи: регрессия.
Метрика: MAE — средняя абсолютная ошибка.

## Источник данных

Wildberries-dataset-sample (Bright Data).
https://github.com/luminati-io/Wildberries-dataset-sample

Исходных строк: 1000.
После очистки: 948.

## Подготовка данных

| Шаг | Решение | Строк |
|---|---|---|
| загрузка | Исходный CSV Wildberries-dataset-sample из GitHub | 1000 |
| дубли | Полных дублей: 0, повторов SKU: 0. Строки сохранены. | 1000 |
| невозможные значения | Удалены 52 товара с нулевой final_price. У 34 другие цены положительные, у 18 все три цены нулевые. Целевая цена неизвестна, поэтому эти строки исключены из набора для прогнозирования. | 948 |
| пропуски | Рейтинг заполнен медианой с флагом. Остальные пропуски заполнены Unknown. | 948 |
| выбросы | IQR: initial_price — 98, final_price — 124, membership_price — 109, review_count — 155. Проверенные максимумы могут быть реальными. Выбросы сохранены, clip и удаление не применялись. Для final_price и review_count исследован log1p. | 948 |

## Новые признаки

- review_count_log — логарифм количества отзывов.
- name_length — длина названия товара.
- has_brand — наличие бренда.

После кодирования получено 30 числовых признаков.

## Разделение данных

Train: 746 строк.
Test: 202 строки.

Использовано групповое разделение по бренду и названию.

## Проверка утечки

Исключены initial_price и membership_price.

Корреляция initial_price с final_price: 0.952.
